# CNC-Pult-Updates (privat)

Nur die fertigen Installationsdateien des CNC-Pult-Verbindungsprogramms.
Neue Version: `release/CNC-Pult-Setup.exe`, `release/VERSION` und `release/NOTES.md` ersetzen und pushen –
die GitHub-Action legt daraus die Release an (mit SHA256-Prüfsumme). Das Verbindungsprogramm findet sie
über einen Lese-Schlüssel und aktualisiert sich nach Rückfrage selbst.
